## Claude Code

- The file-by-file convention above (AGENTS.md, "Working convention") applies to every
  non-test file change, not just the rebuild: one file, shown and agreed, then written.
- A local, untracked `refactor/` directory holds the planning notes, the decision log
  (`refactor/decisions/`) and the cold-start brief (`refactor/HANDOFF.md`). Read it at the
  start of a rebuild session when it is present.
